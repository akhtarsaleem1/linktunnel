Long-Distance Relay Setup

To connect devices on completely different networks/cities, run a lightweight zero-knowledge relay anywhere reachable.

1. On any Cloud VPS (Ubuntu/Debian/Docker): node bin/linktunnel.mjs relay --port 4320
2. Or expose a Local Relay instantly via Cloudflare Quick Tunnel (no VPS needed): cloudflared tunnel --url http://localhost:4320
3. Or test right now on localhost / LAN: Click Start Local Relay in the top bar, then click Use Local in the Share panel.
